# 도쓰

22년 합격자 도쓰(blog.naver.com/dreammonkey83)의 PDF 와, 그것을 같은 이름으로 옮긴 md.
**md 가 이제 내 자료의 원본**이다 — 여기에 필요한 정보를 덧붙여 간다.

| md | 무엇 | 크기 |
|---|---|---|
| `[민소] 목차 업로드 by 도쓰.md` | 편·장·논점 목록 (「N개」= 그 장의 큰 논점 수) | 1쪽 |
| `[민소] 암기장 업로드 by 도쓰.md` | 논점별 답안 뼈대 · template · 두문자 | 24쪽 |
| `[민소] 자료 업로드 by 도쓰.md` | 두문자마다 풀어 쓴 판시·문장 | 37쪽 |
| `[특허] 암기장 자료 업로드 by 도쓰.md` | 특허 암기장 (제2장～제9장 · 단문) | |
| `[특허] 자료 업로드 by 도쓰.md` | 특허 자료 | |

## 읽는 법

- 머리: `##` 편 · `###` 장(특허는 장 띠) · `####` `<논점>`. `{… template}` 와 장 안의 띠(원시적 병합 등)는 굵은 단락.
- **굵은 말** = 원문의 굵은 글씨(두문자 `(부모실남)`, 두문자 글자) + 자료의 빨간 글자(두문자 글자로 시작하는 낱말).
  빨간 글자는 어절 끝까지 잡고 조사를 뗐다 — 경계가 어긋난 곳은 손으로 고친다.
- `곽B 7회-2-1` · `이B 1회-2-2` 같은 출처 표기는 원문 그대로.

## 첫 판을 만든 방법 (2026-11-08)

`python 도쓰변환.py` — 한컴 PDF 라 글자·굵기·색을 그대로 읽었다(OCR 없음). 2단을 단마다 위→아래로 읽고,
PDF 줄바꿈을 이어 붙였다. 확인한 것:

- 굵은 두문자 수 PDF ↔ md: 민소 암기장 415/415 · 민소 자료 369/369 · 특허 자료 263/263 · 특허 암기장 362/370(md 쪽이 조각을 더 셈).
- 민소 암기장에서 줄 잇기가 틀린 11곳을 손으로 갈랐다(관할 · 소송물 · 증명방해 · 공동소송 · 참가 등).
  공동소송 요건의 오른쪽 예시 칸은 두문자 `(공합총연불)` `(동주)` 줄 끝으로 옮겼다(그 자리에 주석).

**이제 손으로 고친다. `도쓰변환.py` 를 다시 돌리지 않는다** — `--덮어쓰기` 를 주면 덧붙인 것이 날아간다.
`--잇기`(PDF 줄을 이은 자리) · `--세기`(굵은 말 수 대조)는 읽기만 하므로 돌려도 된다.
