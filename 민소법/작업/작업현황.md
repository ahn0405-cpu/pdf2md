## 다음에 할 일

두 갈래다.

1. **새로 생성 — 076부터, 사용자가 지시할 때만.** 사용자가 앞 노트를 보고
   다음 범위를 말한다. 시키지 않은 노트를 미리 만들지 않는다.
2. **① 고쳐 쓰기 — 남은 기존 노트** (045 · 057 · 058 · 060 · 062 · 063). 아래 「파일별 남은 것」.
   063 의 78다2448 은 071 이 사실관계까지 갖춘 블록을 새로 세웠으므로, 063 쪽 ①은
   071 을 가리키는 형태로 고친다(SKILL 「같은 사건번호가 서로 다른 두 절에 나오고 판시도 다른 경우」).

①을 고쳐 쓸 때는 한 파일씩 이렇게 돈다.

```bash
cd 민소법/작업/도구
python3 전말덤프.py 058     # 지금 쓴 것 + 사례집 지문 + 판시를 한자리에
#   → 그 재료로 「상황」/「주장과 소 제기」를 쓴다
#   → 전말고침.py 의 고친다(경로, [(열쇠, 새 본문), ...]) 로 갈아 끼운다
python3 전말검사.py 058     # 0 0 0 이 되었는지
python3 검사.py 058         # 골격이 깨지지 않았는지
git add -A && git commit -F - <<'MSG'
...
MSG
```

**열쇠는 그 블록에만 있는 짧은 토막**으로 잡는다. 줄바꿈 자리를 외워 긴 문자열로
찾으면 어긋난다(실제로 몇 번 어긋났다). 열쇠가 짧아 다른 블록에 먼저 걸리는 것도
조심한다.

## 내가 끝낼 수 없는 일 — 원본 PDF 대조

`references/확인목록.md` 의 「확정값」 칸이 비어 있다. **소스가 뭉개진 자리**라
원본 PDF를 보지 않으면 복원할 수 없다.

- 사건번호 깨짐 — 지금 있는 노트 중에는 **053·054** 에 `<!-- 확인필요 -->` 주석이
  남아 있다. 나머지 행은 새로 생성할 노트(065~100) 것이다
- 재구성한 표 **3건** — 068 · 073 · 099 (셋 다 새로 생성할 노트)

확정값을 채워 커밋하면 이렇게 반영한다.

```bash
python3 확인적용.py --검사    # 채워진 줄이 있나
python3 확인적용.py           # 노트에 반영하고 주석을 지운다
```

행 번호로 찾지 않으므로 노트가 그 사이 고쳐져도 괜찮다.
