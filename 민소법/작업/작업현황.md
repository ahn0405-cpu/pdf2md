## 지금 서 있는 자리

노트 **42개**(045~100 중)가 있고 전부 소스 전수 대조를 마쳤다.
**14개는 지우고 새로 생성한다** — 아래 「새로 생성할 노트」.
마지막으로 한 일은 **① 사건의 전말을 사례로 다시 쓰는 것**이고, 049~055 까지 끝났다.

```
$ python3 전말검사.py
합계  판례 273  ①없음 43  甲乙없음 104  안나뉨 119
```

| 항목 | 뜻 | 남은 것 |
|---|---|---|
| `①없음` | 「② 판례의 태도」 앞에 ①이 아예 없다. **골격 위반** | 43 |
| `甲乙없음` | 상황에 등장인물이 없다 — 사례가 아니라 요건 서술 | 104 |
| `안나뉨` | 「상황」/「주장과 소 제기」를 합쳤는데 이어받기가 아니다 | 119 |

`진단.py` 의 여섯 항목은 **046의 2건·055의 1건만 남았고 둘 다 오탐**이다
(접속어 없이 쓴 이유를 스크립트가 못 읽는다). 나머지는 전부 0이다.

## 다음에 할 일 — 056부터 차례로

한 파일씩 이렇게 돈다.

```bash
cd 민소법/작업/도구
python3 전말덤프.py 058     # 지금 쓴 것 + 사례집 지문 + 판시를 한자리에
#   → 그 재료로 「상황」/「주장과 소 제기」를 쓴다
#   → 전말고침.py 의 고친다(경로, [(열쇠, 새 본문), ...]) 로 갈아 끼운다
python3 전말검사.py 058     # 0 0 0 이 되었는지
python3 검사.py 058         # 골격이 깨지지 않았는지
git add -A && git commit -F - <<'MSG'
...
MSG
```

**열쇠는 그 블록에만 있는 짧은 토막**으로 잡는다. 줄바꿈 자리를 외워 긴 문자열로
찾으면 어긋난다(실제로 몇 번 어긋났다). 열쇠가 짧아 다른 블록에 먼저 걸리는 것도
조심한다.

`①없음` 43건은 ①을 **새로 쓰는** 일이라 나머지와 성질이 다르다.
099(14건)·076(9건)·097(6건)에 몰려 있다.

## 내가 끝낼 수 없는 일 — 원본 PDF 대조

`references/확인목록.md` 의 「확정값」 칸이 비어 있다. **소스가 뭉개진 자리**라
원본 PDF를 보지 않으면 복원할 수 없다.

- 사건번호 깨짐 — 노트 **19개**에 `<!-- 확인필요 -->` 주석이 남아 있다
- 재구성한 표 **3건** — 068 · 073 · 099

확정값을 채워 커밋하면 이렇게 반영한다.

```bash
python3 확인적용.py --검사    # 채워진 줄이 있나
python3 확인적용.py           # 노트에 반영하고 주석을 지운다
```

행 번호로 찾지 않으므로 노트가 그 사이 고쳐져도 괜찮다.
