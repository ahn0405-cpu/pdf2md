# 원본 대조 확인 목록

## 쓰는 법 — 둘 중 하나

**① 확정값만 적어 두고 반영은 맡긴다** (권함)

아래 표의 **「확정값」 칸**에 원본에서 읽은 값을 적는다. 그것만 하면 된다.
다음 작업 때 `확인적용.py` 로 노트에 한꺼번에 반영하고 주석을 지운다.
칸이 빈 줄은 아직 대조하지 않은 것으로 본다.

```
python3 확인적용.py            # 확정값이 적힌 줄만 노트에 반영
python3 확인적용.py --검사     # 반영하지 않고 무엇이 바뀔지만 본다
```

**② 노트를 직접 고친다**

`민소법/노트/단권화/*.md` 의 해당 행을 고치고 `<!-- 확인필요: … -->` 주석을 지운다.
이때도 아래 표의 「확정값」 칸을 채워 두면 나중에 되짚을 수 있다.

**어느 쪽이든 `민소법/출력/기본서`(변환 원본)는 손대지 않는다.**
원본은 깨진 채로 두고 노트에서 바로잡는 방식이라, 원본을 고쳐도 노트에 반영되지 않는다.

- 남은 것 찾기: `grep -rn "확인필요" 민소법/노트/단권화/`
- 남은 개수: `grep -rc "확인필요" 민소법/노트/단권화/ | grep -v ":0"`

총 **29건**이고 **13건 반영 완료**(049·052·065 와, 076～100 을 새로 만들며 원본으로 확정한 078～100 의 10건), **16건 남음**이다.
남은 것은 모두 기존 노트(053～075) 것이다. 아래 세 갈래로 나뉜다.

`✔반영` 이 붙은 줄은 노트에 이미 들어갔고 주석도 지워졌다. 다시 채우지 않아도 된다.

**065와 078은 같은 판례**(자백간주 후 공시송달)였고, 두 곳 모두 원본에서 `87다카961` 이다
(`*` 가 「카9」를 삼켰다). 065 는 `확인적용.py` 로 반영했다.

**100은 성질이 다르다.** 사건번호가 깨진 것이 아니라 원본에도 없다.
☑ 박스 표지가 깨진 자리(`| 1.학설`·`； 2.判例`·`: 3.검토`)는 점선 박스의 왼쪽 테두리가
줄 머리 잡티로 남은 것일 뿐, 사건번호가 떨어져 나간 흔적이 아니었다.

## D. 두문자·용어 정정 — 사용자가 적는다

책이나 강의와 다르게 적힌 두문자·용어를 발견하면 **한 줄씩 적는다.** 논점 번호와 틀린 것·맞는 것만 있으면 된다.
반영은 다음 작업 때 한다. 두문자가 바뀌면 풀이 문장(「**명**시적 **일**부청구…」)도 새 글자에 맞게
다시 써야 해서 자동 치환으로는 하지 않는다. 반영할 곳은 단권화 노트 → 목차집이고,
암기노트는 노트에서 다시 뽑을 때 따라온다. 반영하면 「반영」 칸에 ✔ 를 단다.

| 046 | `[명일동내]` | `[명일동나]` | 중복소제기 判 — 기본서 OCR 도 「내」로 나와 있었다 |  |

## 고친 뒤

사건번호를 고치면 그 번호로 **사례집 뱃지를 다시 대조**할 수 있다.
복원된 번호가 사례집에 실려 있으면 뱃지가 붙어야 하므로, 확정 후
`python3 색인.py <논점번호>` 를 돌려 본다.
