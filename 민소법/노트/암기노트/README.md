# 암기노트

**시험장에 들고 갈 단 한 권**이다(2026-10-19 부터). 템플릿의 답안 순서를 뼈대로, 외울 문언만 빈칸으로 싣는다.

| 문서 | 역할 | 순서 |
|---|---|---|
| `../목차집/` | 기본서 내용과 순서의 요약 | 기본서 |
| `../템플릿/` | 사례집 답안 뼈대 — 단계·배점·두문자 | 답안 |
| 암기노트 (여기) | 템플릿 순서 + 빈칸 문언 | 답안 (템플릿이 없는 논점은 기본서) |

- 처음에는 목차집 문장 전체에 빈칸을 뚫어 보았다. 그랬더니 흔한 낱말(「공시송달」 55회 등)이 어디서나 가려지고,
  낱말 중간이 잘리고, 판례 요약과 판시가 같은 답으로 두 번 가려졌다. 그래서 목차집에서는 **항목 이름만** 가져온다.
- 붙는 것은 둘이다. **기본서 문언**(노트의 의의·요건·검토 인용)과 **중요 판례 판시**(`표준판례` 이거나 사례집 뱃지).
  빈칸은 노트가 채점 단위로 단 BOLD 그대로다.
- 목차순 판과 답안 set 판(`CH08_변론_답안셋.md`)을 따로 두던 것을 한 권으로 합쳤다 — 같은 문언을 두 번 실었기 때문이다.

＿ 하나가 한 글자다. 띄어쓰기와 조사(을·를·에·의 …)·기능어(것·수·경우 및 …)는 빈칸 안에 그대로 둔다.
「있다·없다·아니다」 같은 술어는 결론의 방향이 곧 답이므로 가린다.

**`작업/도구/암기노트.py` 가 뽑는다. 손으로 고치지 않는다** — 다시 뽑으면 덮어쓴다.
답안 순서가 이상하면 템플릿을, 항목이 이상하면 목차집을, 문언·빈칸이 이상하면 단권화 노트를 고친 뒤 다시 뽑는다.

```bash
cd 민소법/작업/도구
python3 암기노트.py 08         # 한 장만
python3 암기노트.py 052        # 한 논점만 화면에 (장 파일은 안 건드린다)
python3 암기노트.py --검사 08  # 짝 없는 중요 판례 · 약한 짝 · 블록 없는 template 단계 · 15자 넘는 빈칸
```

## 한 논점의 모양

```
# 052 처분권주의
## {일부인용 template} — 단순이행청구에 상환이행·선이행판결 · H-1 · H-2
1. 문제의 소재 `0.5`
2. 처분권주의 위반 여부 `1.5`
   - (1) 의의·취지 [제203조]
       > i) 법원은 ❶(＿＿＿가 …
## {연대·개별책임 template} — …
   - (1) 의의·취지 [제203조]
       > → {일부인용} 2.(1)          ← 같은 논점 안 두 번째는 처음 자리를 가리킨다
## 함께 나오는 사례                  ← 다른 논점·다른 장의 template 을 가리키는 줄
## 그 밖에                           ← 어느 단계에도 안 붙은 블록 — 목차집 항목 이름 아래, 목차집 순서
## 052 정답
```

| 무엇 | 어디서 |
|---|---|
| template 뼈대 | 템플릿의 `{유형 template}` 단계 줄. 이름만 싣는다(` — ` 뒤 요약은 뺀다. 두문자·배점·쓰는 법·학설 이름은 둔다) |
| 단계 ↔ 블록 | 단계 이름에 든 목차집 항목 이름 · 두문자 · 학설 이름+괄호 · 「의의」 · 글자 겹침 — `작업/references/템플릿.md` |
| `그 밖에` 뼈대 | 목차집 논점의 항목 이름 — 줄 머리의 `**이름**`(뒤 `기출` 포함), ` — ` 앞부분, `학설:` 같은 짧은 머리, 짧은 번호 줄(「1. 판단기준」) |
| 빼는 것 | 목차집의 `**핵심**` 줄, 📝 메모, 표, 주석 |
| `>` 기본서 문언 | 노트에서 판례 블록 밖의 `>` 인용 중 BOLD 가 있고 해설(「니다」)·사례(甲乙)가 아닌 것. 글자 겹침이 가장 큰 목차집 줄 아래에. 짝이 약하면(0.3 미만) 노트에서 놓인 절 제목으로 항목을 찾는다 |
| `> **判**` 판시 | 중요 판례만. 목차집 (判) 줄과 짝지어 그 아래에. 엇갈리는 짝은 `암기노트.py` 의 `짝고침` 표 |
| 분절 | 판시·문언을 `i) ii) iii)` 토막으로 한 줄씩(문장 끝·쉼표·연결어미, 빈칸 안은 자르지 않음). 판시에 이미 i) 가 있으면 그대로 — 합격자 도쓰 「자료」에서 가져옴 |
| 학설 | 노트의 학설 표(`견해 | 논거 | 결론`)를 `견해: 논거 → 결론` 한 줄씩. 견해명은 가리지 않고, 목차집 학설 줄의 `(判·검토)` 를 붙인다 |
| 반복 | 같은 논점 안에서는 한 번만 싣고 다음부터 `→ {이름} 2.(1)`. 다른 논점의 template 이 `(→ 052)` 로 끌어온 블록은 그 논점에서 다시 싣는다 |
| 빈칸 번호 | 인용마다 ❶ 부터 다시 |
| 정답 | 논점 끝 `## NNN 정답` — 판시는 사건번호, 문언은 붙은 단계·항목 이름을 머리로 |

- **표를 쓰지 않는다.** 프린트해서 보므로, 표는 칸 여백 때문에 쪽수만 늘린다.
- **정답 줄에 사건번호가 있다.** 목차집에는 사건번호가 없으므로 단권화 노트로 되짚어 가는 길은 여기뿐이다.
- **노트에 기본서 문언이 `>` 인용으로 없는 자리**(예: 052 「II. 내용」 i)～iii)은 노트 해설체)는 항목 이름만 남는다.
- 1위 논점이 다른 장인 사례(CH08 의 I-3 · H-9 · B-10 …)는 그 장을 템플릿으로 바꿀 때까지 `함께 나오는 사례` 의 가리킴으로만 나온다.
- 지금 새 방식으로 뽑은 장은 **CH08 하나**다. CH05～07 은 옛 방식(노트 판례만, 표 형식) 그대로 남아 있다.
