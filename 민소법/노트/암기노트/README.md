# 암기노트

단권화 노트의 **판시 원문 BOLD** 를 빈칸 `❶(＿＿)` 으로 바꿔 장(CHAPTER) 단위로 묶은 것이다.
빈칸의 길이는 BOLD 덩어리의 글자 수(공백 제외)다.

**`작업/도구/암기노트.py` 가 뽑는다. 손으로 고치지 않는다** — 다시 뽑으면 덮어쓴다.
빈칸이 이상하면 단권화 노트의 BOLD 를 고친 뒤 다시 뽑는다.

```bash
cd 민소법/작업/도구
python3 암기노트.py            # 노트가 있는 장 전부
python3 암기노트.py 05         # 한 장만
python3 암기노트.py 046        # 한 논점만 화면에 (장 파일은 안 건드린다)
python3 암기노트.py --검사     # 15자 넘는 빈칸 · 판시 없는 판례
```

| 무엇 | 어디서 |
|---|---|
| 장의 경계 | 기본서 목차(CONTENTS). 예: 05 소송물 = 045~046 |
| 수록 판례 | `표준판례` 이거나 사례집 뱃지(`E-5`)가 붙은 것. 같은 판시가 두 번 나오면 한 번만 |
| 쟁점 이름 | 노트의 대절 제목 + 판례 헤딩의 라벨. ☑ 박스 안이면 ☑ |
| 두문자 줄 | 노트 「한 줄 요약」의 두문자와 풀이 |
| ⚠️ 줄 | 노트 「구별 개념」의 첫 문장. 노트 안의 자리(「위 1)」 등)를 가리키는 문장은 건너뛴다 |
| 기출연도 | 기본서 머리말의 `exam_years` |

형식 기준은 `../../작업/samples/암기노트_CH06_소송물.md` 다. 샘플과 다른 점이 둘 있다.

- **장 번호는 목차를 따른다.** 샘플의 「CHAPTER 06 소송물」은 목차의 05 가 맞다
  (06 은 소송절차 개시 — 047~049).
- **정답표에 사건번호 칸이 있다.** 단권화 노트로 되짚어 가기 위해서다.
