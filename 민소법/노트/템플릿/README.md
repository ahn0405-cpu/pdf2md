# 템플릿

사례집 문제를 **답안 순서**로 묶은 뼈대(단계 · 배점 · 두문자)를 장(CHAPTER) 단위로 둔 것이다(2026-10-19 부터, CH08 이 처음).
사례집 설문마다 배점이 가장 큰 논점에 `{유형 template}` 을 두고, 다른 논점에는 가리킴 한 줄을 둔다.

| 문서 | 역할 | 순서 |
|---|---|---|
| `../목차집/` | 기본서 내용과 순서의 요약 | 기본서 |
| 템플릿 (여기) | 사례집 답안 뼈대 | 답안 |
| `../암기노트/` | 시험장에 들고 갈 단 한 권 — 템플릿 순서 + 빈칸 문언 | 답안 |

**손으로 쓴다.** 문언은 여기 쓰지 않는다 — `암기노트.py` 가 단계 이름으로 목차집 항목을 찾아 그 아래 빈칸 문언을 붙인다.
그래서 템플릿을 고치면 암기노트를 다시 뽑는다. 작성 원칙은 `../../작업/references/템플릿.md`.

```bash
cd 민소법/작업/도구
python3 목차재료.py 066        # 재료 — 「4 사례집 답안 목차」(제목과 배점)
python3 암기노트.py --검사 08  # 블록이 안 붙은 template 단계(빈단계)
python3 암기노트.py 08         # 다시 뽑기
python3 목차재료.py --검사     # 사례 번호 빠짐 0
```

- 지금 템플릿이 있는 장은 **CH08** 하나다. 다른 장은 목차집 논점 끝 `▸ 사례로 나오면` 블록(옛 형식)에 사례 줄이 있다.
- 1위 논점이 다른 장인 문제는 `→ 076 재판상 자백 (CH09)` 처럼 가리킴만 두었다. 그 장을 템플릿으로 바꿀 때 template 을 만든다.
