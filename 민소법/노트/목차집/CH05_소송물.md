# 045 소송물이론

**핵심** 무엇이 「하나의 소송물」인가. 구이론(判)은 **청구원인(실체법상 권리)**마다 소송물을 따로 센다. 그래서 청구원인이 다르면 별개 소송물이고, 같은 청구원인 안에서 그것을 뒷받침하는 사유만 다르면 공격방어방법의 차이에 그친다.

**의의** 소송물은 법원이 심판하는 대상이다. 무엇이 소송물인지 정한 명문 규정이 없어 학설이 갈린다.

1. **소송물이론 일반** — 무엇을 기준으로 소송물을 가르나
   - 학설: **구이론(判)**(실체법상 권리가 소송물, 청구원인으로 식별) / 신이론 ① 일지설(신청(청구취지)만으로 식별, 금전 등 대체물은 사실관계를 참작) ② 이지설(신청 + 사실관계)
   - 判: 불법행위에 기한 손해배상청구에 채무불이행에 기한 손해배상을 명하면, 신청하지 않은 사항을 판결한 것이어서 처분권주의에 반한다.
   - 검토: 신이론은 신청이 같으면 같은 소송물로 보아 당사자 구제에 미흡하고, 소송물을 넓게 잡아 법원의 심리부담이 커진다 → 구이론
   - 재판상 이혼사유도 사유마다 별개의 소송물이다 → 법원은 원고가 주장한 이혼사유만 심판한다(判).
   - ☑ 구이론·判은 **다른 소송물**로 본다 (일지설은 같은 소송물, 이지설은 다른 소송물)
     - 대여금청구 ↔ 어음채권에 기한 청구
     - 매매에 기한 이전등기청구 ↔ 취득시효완성에 기한 이전등기청구
     - 대물변제계약에 기한 이전등기청구 ↔ 매매계약에 기한 이전등기청구(判)
     - 선행판결·약정 위반을 원인으로 한 금지·손해배상청구 ↔ 부정경쟁방지법상 영업비밀침해를 원인으로 한 금지·손해배상청구(判)
     - 소유권 상실을 이유로 한 불법행위 손해배상 ↔ 보존등기 말소의무의 이행불능으로 인한 손해배상 → 주장하지 않은 쪽을 인정하면 처분권주의 위반(判)
2. **이행의 소** — 청구원인이 다르면 별개, 같은 청구원인 안에서 사유만 다르면 공격방어방법
   1. 신체상해에 따른 손해배상 `기출 22·24` — 손해는 몇 개의 소송물인가
      - 학설: 손해1개설(총액에만 관심) / 손해2분설(재산상·정신적 손해는 성질이 다르다) / **손해3분설(判·검토)**
      - 判: 적극적 재산상 손해(치료비 등) · 소극적 재산상 손해(일실수익) · 정신적 손해의 세 가지로 나뉜다.
      - 다만 같은 손해 안의 항목(기왕치료비·향후치료비·개호비 등)은 공격방법일 뿐이다 → 불이익변경 여부도 항목별로 비교하지 않는다(判).
   2. 진정명의회복을 위한 이전등기청구 ↔ 등기말소청구 `[등회목동소방성]`
      - 判: 둘 다 진정 소유자의 **등기명의 회복**이 목적이고 **소유권에 기한 방해배제청구권**으로 근거·성질이 같다 → 소송물은 실질상 동일하다.
      - 학설: 동일 소송물설(어느 방법이든 결과가 같다) / 별개 소송물설(청구취지가 달라 소송물은 다르나 신의칙상 후소 불허)
      - ☑ 진정명의회복 이전등기청구는 허용되나 — 이미 자기 앞으로 등기가 있었거나 법률로 소유권을 취득한 자는, 말소를 구하는 대신 현재 명의인에게 직접 이전등기를 구할 수도 있다(判).
        긍정설(말소와 결과 차이가 없고 최종 명의인만 상대하면 돼 간명 — 검토) / 부정설(등기부는 물권변동 과정을 그대로 반영해야 한다)
   3. 원인무효(진정명의회복) 말소청구 ↔ 계약해제에 의한 말소청구 `[진해원달]`
      - 判: 전소는 소유권에 기한 방해배제, 후소는 계약해제에 따른 원상회복 → 청구원인이 달라 전소 기판력이 후소에 미치지 않는다.
      - 주의: 전후소 모두 「원인무효」 말소를 구하면서 무효·해제 같은 개개 사유만 달리하면 **같은** 소송물이다.
      - 같은 결로 별개: 소유권에 기한 인도 ↔ 약정에 기한 인도(判) · 신탁해지만을 이유로 한 이전등기 ↔ 신탁해지를 원인으로 소유권에 기한 이전등기(判) · 사기취소를 원인으로 한 저당권말소 ↔ 피담보채무 부존재(해지·원상회복)를 원인으로 한 저당권말소(判)
   4. 소유권에 기한 반환 ↔ 점유권에 기한 반환 — 소유권에 기해 미등기건물 반환을 구하는 청구에 점유권에 기한 반환청구가 당연히 포함되지는 않는다 → 별개(判)
   5. 점유개시원인이 다른 취득시효 이전등기청구 `[대중 물취공기]` — 「대물변제받아 점유를 시작했다」고 해서 졌는데 다시 「증여받아 점유를 시작했다」고 주장 → 점유개시원인은 공격방어방법일 뿐 같은 소송물 → 기판력에 저촉(判)
   6. 피담보채권을 달리하는 가등기 본등기청구 — 등기원인은 그대로 매매예약완결이고 피담보채권만 대여금 → 손해배상채권으로 바꾼 것 → 공격방어방법의 변경일 뿐 청구의 변경이 아니다(判)
   7. 원인무효 사유를 달리하는 말소등기청구 `[물말원원 뒷개독공]` — 말소등기청구의 소송물은 그 등기의 말소청구권이고 청구원인은 등기원인의 무효다 → 무효를 뒷받침하는 개개 사유는 독립된 공격방어방법 → 모두 전소 변론종결 전 사유라면 후소는 기판력에 저촉(判)
   8. 사유를 달리하는 부당이득반환 ↔ 해제에 의한 원상회복 `[부원공 어패다기]` — 원상회복은 부당이득의 특칙이고, 계약 불성립·취소·무효·해제는 「법률상 원인 없음」을 뒷받침하는 공격방법일 뿐 → 어느 사유로 패소한 뒤 다른 사유로 다시 청구하면 기판력에 저촉(判)
3. **확인의 소** — 소유권확인에서 취득원인(매매·증여·시효 등)이 다르면 소송물도 다른가 `[법확전원다]` `[증취상동]`
   - 학설: **다수설(검토)**(소송물은 실체법상 권리 자체, 취득원인은 식별기준이 아니다) / 소수설(이지설 — 청구원인 사실로 특정)
   - 判 기판력: 소유권확인판결이 확정되면 변론종결 전에 **다른** 취득원인 사실이 있었더라도 기판력이 거기까지 미친다.
   - 判 재소금지: 증여를 원인으로 한 소유권확인청구를 취하한 뒤, 상속을 원인으로 지분소유권확인을 구하는 것은 동일한 소가 아니다.
4. **형성의 소** — 구이론(실체법상 형성권의 주장) / 일지설(형성을 구할 수 있는 법적 지위의 주장) / 이지설(그 법적 지위 + 청구원인 사실관계)

▸ **사례로 나오면** — 「소송물이론(구이론·判)」을 세운 뒤, 두 청구가 **청구원인부터 다른지**, **같은 청구원인 안의 사유만 다른지**로 포섭한다.
- 외국 법원 계속 중 다른 청구원인으로 별소 → 중복소제기 요건 중 소송물 동일 여부(3.5) — B-3
- 대여금 소송으로 어음채권의 시효도 중단되나 → 시효중단(3) — H-16
- 신체상해 손해배상의 금액 특정 → 신체상해 소송물(4) → 소극적 석명(5) — H-19
- 일부청구 확정 후 잔부청구 → 기판력 객관적 범위(2.5) 안에서 신체상해 소송물 — E-4
- 부당이득반환 패소 확정 후 다른 사유로 재청구 → 기판력 객관적 범위·작용국면(5) 안에서 소송물이론 `[부원공 어패다기]` — E-1
- 계속 중인 소와 소송물이 같은가 → 전소 계속 중(3) → 당사자 동일(3.5) → 소송물 동일(3.5) `[부원공 어패다기]` — G-3
- 소유권확인 소장에 취득원인을 써야 하나 → 소송물 특정을 위한 청구원인 기재(2.5) → 소유권확인의 소 청구원인 기재 요부(3) — I-12
- 확인판결 확정 후 다시 확인청구 → 객관적 범위·작용국면(4) 안에서 확인의 소 소송물 → 시적범위·차단효(4) — M-24

E-1 · H-19 · I-12 는 사례집 변환에서 문제 번호가 깨져(「E7」 「H니9」 「1-12」) 앞뒤 번호로 추정한 것이다.

# 046 일부청구 `기출 2011, 2022`

**핵심** 일부만 청구하면 나머지는 어떻게 되는가. 소송물을 일부로 보느냐(명시설)가 중복소제기·시효중단·기판력·과실상계를 전부 정한다.

**의의** 수량적 가분채권을 나누어 일부만 청구하는 것. 소송비용 절약과 시험소송이 목적이다.

1. **소송물** `기출 11·22` — 소송물은 청구한 일부뿐인가, 채권 전부인가 `[일외별명일]`
   - 학설: 긍정설(처분권 존중 → 일부) / 부정설(판결 모순 방지·1회적 해결 → 전부) / **명시설(判)** — 일부청구임을 명시하면 일부, 아니면 전부
   - 判: 치료비 일부만 특정해 청구하고 나머지는 별도 소송으로 구하겠다고 **명시적으로 유보**하면, 소송물은 청구한 일부에 한정된다.
   - ☑ 무엇이 「명시」인가
     - ○ 협의분할의 소급효로 상속재산이 원고 단독 소유가 되었는데, 이를 모르고 **법정상속분만** 구한 경우(判)
     - × 변론종결일에 가까운 날까지 든 **치료비임을 밝혀** 청구한 경우 — 종결 때 예상할 수 없던 손해가 아닌 한(判)
     - × 공유지분 범위를 정확히 몰라 **일부 지분만** 이행청구한 경우(判)
2. **중복소제기** — 전소 계속 중 나머지를 후소로 청구하면 중복소제기(제259조)인가 `[명일동내]`
   - 학설: 긍정설(소송물은 전부, 확장하면 된다) / 부정설(소송물은 일부) / 단일절차병합설(이송·병합을 시도하고 안 되면 소권남용 각하) / **명시한 때에만 부정설(判)**
   - 判: 일부청구임을 명시했다면 소송물은 그 일부뿐이므로, 전소 계속 중 유보한 나머지를 별소로 내도 중복소제기가 아니다.
   - 判: 다만 전소가 **사실심**에 계속 중이어서 청구취지 확장으로 쉽게 구할 수 있었는데도 별소를 내면 **소권남용 → 각하**. 전소가 대법원에 있으면 확장할 수 없으니 남용이 아니다.
3. **시효중단** `기출 11` — 소를 내면 시효가 중단되는데(제265조), 일부만 청구하면 어디까지 중단되나
   - 학설: 일부중단설(실제 청구한 범위만) / 전부중단설(소를 낸 이상 권리 위에 잠잔 것이 아니다 → 전부) / 절충설(명시하면 일부, 아니면 전부)
   1. 원칙 `[일나시 나소시]` — 일부청구는 나머지에 시효중단 효력이 없고, 나머지는 소를 내거나 청구를 확장하는 서면을 낸 때 비로소 중단된다(判).
   2. 확장할 뜻을 밝힌 경우 `[종확나시]`
      - 「감정결과에 따라 청구금액을 확장하겠다」고 소장에 객관적·명백히 표시 → 채권 **전부** 중단(判, 종전)
      - 그러나 소송이 끝날 때까지 **실제로 확장하지 않으면** 나머지는 중단되지 않는다(判, 최근 — 「실제 확장」 요건을 더함)
      - 확장 뜻을 표시했어도 뒤에 특정 부분을 청구범위에서 **명시적으로 제외**하면, 그 부분은 처음부터 소제기가 없던 것 → 중단 ×(判)
   - ☑ 확장하지 않은 나머지는 어떻게 살리나 — 소송 중에는 **최고**로 권리를 행사하는 상태가 이어진다.
     - 소송이 끝난 뒤 **6월 내**에 재판상 청구·압류·가압류(민법 제174조)를 하면 나머지도 중단된다(判)
     - 소송 중에 그 조치를 했다면 시효중단 효력은 **당초 소제기 때부터** 유지된다(判)
4. **기판력** `기출 22` — 일부청구 판결이 확정된 뒤 나머지를 후소로 청구하면 기판력에 저촉되나 `[명일기나]`
   - 학설: 긍정설(일부만 소송물 → 저촉 ×) / 부정설(전부가 소송물 → 저촉) / **명시설(判)**
   - 判: 일부에 대해서만 판결을 구한다고 명시했다면 소송물은 그 일부이므로, 확정판결의 기판력은 나머지 청구에 미치지 않는다.
5. **과실상계** — 일부만 청구했을 때 과실상계를 손해 전액에서 하나, 청구액에서 하나 `[과전통처]`
   - 학설: **외측설(判)**(전액에서 상계한 뒤 남은 금액과 청구액 중 작은 것을 인용) / 안분설(청구액에서 상계) / 절충설(명시하면 안분설, 아니면 외측설)
   - 判: 손해 **전액**에서 과실비율만큼 감액한다. 그것이 일부청구하는 당사자의 **통상적 의사**이고, 처분권주의에도 어긋나지 않는다.
   - 예: 손해 1억 원, 원고 과실 4할, 3천만 원 청구 → 외측설은 6천만 원이 남으므로 **3천만 원 전액** 인용 / 안분설은 1,800만 원
   - 과실은 당사자가 주장하지 않아도 법원이 **직권**으로 심리·판단한다(判). 상계·변제 항변도 같은 방식으로 계산한다.

▸ **사례로 나오면** — 언제나 「소송물(명시설)」을 먼저 세우고 효과로 내려간다.
- 전소 계속 중 나머지를 별소 → 소송물(4) → 중복소제기(5) — E-2
- 전소 확정 후 나머지를 별소 → 소송물(3~4) → 기판력(4~7) — E-3 · E-6
- 나머지의 시효가 문제 → 소송물(2.5~3) → 시효중단(4~6) — E-5~7
- 과실이 문제 → 과실 직권조사(1.5) → 과실상계(4.5) — E-8
