# 목차집

논점마다 **핵심 · 의의 · 개조식 목차 · 사례** 를 장(CHAPTER) 단위로 묶은 회독용 문서다(도쓰 암기장 양식).
시험장에서 목차를 세우고(사례), 판례 입장과 두문자를 떠올리는(개조식 목차) 데 쓴다.
판시 문언은 같은 장의 `../암기노트/` 에서 빈칸으로 외운다 — 둘은 나란히 펼쳐 보도록 이름을 맞췄다.

**손으로 쓴다.** 생성기가 없으므로 고치거나 메모를 더해도 덮어써지지 않는다.

| 칸 | 무엇 | 근거 |
|---|---|---|
| 핵심 | 논점을 꿰는 물음·명제 한 줄 | 노트 I. 의의 해설 |
| 의의 | 정의 + 취지 한 줄 | 기본서 I. 의의 |
| 개조식 목차 | 쟁점의 물음 · 학설(근거, 判 굵게) · 판례 요건과 결론(判) · 두문자. 사건번호는 쓰지 않는다 | 기본서 원문 (判 위치는 노트로 확인) |
| 사례로 나오면 | 문제 유형마다 큰 목차 순서와 본론 배점 | 사례집 **목차 제목과 배점만** (뱃지가 있는 논점) |

작성 원칙은 `../../작업/references/목차집.md` 에 있다.

```bash
cd 민소법/작업/도구
python3 목차재료.py 068        # 쓸 재료 — 노트 목차·의의·학설·사례집 답안 목차(사례 줄)
python3 목차재료.py --검사     # 아직 없는 논점 · 노트에 없는 두문자
```
