# 특허법 단권화

**민소법과 섞지 않는다.** 두 과목은 원본도 규칙도 결과물도 따로 간다.
공통은 `book2md/` 변환기 하나뿐이고, 그것도 설정은 과목별로 갈라져 있다
(`config-민소법.yaml` / `config-patent.yaml`).

**지금은 변환 진단(`출력/_reports/`)만 있다.** 시작하는 법은
`../book2md/HANDOFF.md` 에 있다.

## 무엇이 어디에 — 민소법과 같은 틀

```
특허법/
├── 출력/                  ← 소스. 변환 결과 (convert all 의 산물)
│   ├── _reports/          변환 진단 리포트
│   ├── 기본서/
│   └── 사례집/
├── 노트/                  ← 결과물
│   ├── 단권화/
│   └── 암기노트/
└── 작업/                  ← SKILL.md · 작업현황.md · references/ · samples/ · 도구/
```

## 어디서 무엇을 하나

| 일 | 어디서 |
|---|---|
| PDF → 마크다운 | **사장님 PC.** 원본 PDF가 거기 있다 |
| 절 점검·매핑 | 어느 쪽이든. `convert --book patent …` |
| 노트 생성 | 리포를 읽는 세션. `작업/SKILL.md` 를 따른다 |

변환 결과가 바뀌면 `출력/` 을 다시 올려야 한다. 절이 바뀌면 노트의 목차도
바뀌기 때문이다. **재변환 → 올리기 → 노트** 순서를 지킨다.

## 노트를 만들기 전에 읽을 것

1. `작업/SKILL.md` — 노트 생성 규칙
2. `작업/samples/` — 형식 기준
3. `../book2md/OUTPUT.md` — **변환물의 한계.** 무엇을 믿고 무엇을 의심할지
