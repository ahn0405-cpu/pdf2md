# 특허법 단권화

**특허법과 섞지 않는다.** 두 과목은 원본도 규칙도 결과물도 따로 간다.
공통은 `book2md/` 변환기 하나뿐이고, 그것도 설정은 과목별로 갈라져 있다
(`config-민소법.yaml` / `config-patent.yaml`).

## 무엇이 어디에

```
특허법/
├── 단권화/
│   ├── SKILL.md              노트 생성 규칙. 이 문서가 기준이다
│   ├── samples/              형식 기준. 규칙과 충돌하면 샘플을 우선한다
│   ├── mapping.yaml          기본서 ↔ 사례집 대응표
│   └── output/               노트 결과물
└── 출력/                      변환 결과 (convert all 의 산물)
    ├── 기본서/                NNN_<논점번호><제목>.md
    └── 사례집/                <그룹>_<주제>.md
```

## 어디서 무엇을 하나

| 일 | 어디서 |
|---|---|
| PDF → 마크다운 | **사장님 PC.** 원본 PDF가 거기 있다 |
| 절 점검·매핑 | 어느 쪽이든. `convert --book 특허법 …` |
| 노트 생성 | 리포를 읽는 세션. `단권화/SKILL.md` 를 따른다 |

변환 결과가 바뀌면 `출력/` 을 다시 올려야 한다. 절이 바뀌면 노트의 목차도
바뀌기 때문이다. **재변환 → 올리기 → 노트** 순서를 지킨다.

## 노트를 만들기 전에 읽을 것

1. `단권화/SKILL.md` — 노트 생성 규칙
2. `단권화/samples/` — 형식 기준
3. `../book2md/OUTPUT.md` — **변환물의 한계.** 무엇을 믿고 무엇을 의심할지
4. `단권화/mapping.yaml` — `confirmed: true` 인 것만 쓴다
