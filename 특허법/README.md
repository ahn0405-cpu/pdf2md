# 특허법 단권화

**민소법과 섞지 않는다.** 두 과목은 원본도 규칙도 결과물도 따로 간다.
공통은 `book2md/` 변환기 하나뿐이고, 그것도 설정은 과목별로 갈라져 있다
(`config-민소법.yaml` / `config-patent.yaml`).

**지금 하는 것은 목차집이다.** 단권화 노트 없이 기본서·사례집 변환물에서 바로 쓴다
(`노트/목차집/README.md`). 변환을 다시 하는 법은 `../book2md/HANDOFF.md` 에 있다.

교재는 박지환 「테마 특허법」 — 기본서 9판(115 논점, 9장) · 사례집 5판(161 문제)
· 기본서 9판 1차 추록 · 사례집 5판 정오표. 바뀐 곳은 `작업/references/정오.md`.

## 무엇이 어디에 — 민소법과 같은 틀

```
특허법/
├── 출력/                  ← 소스. book2md 의 산물. 손대지 않는다
│   ├── _reports/          변환 진단·검증 리포트
│   ├── 기본서/            NNN_<장내번호><논점>.md  NNN = 책 전체 순번(001~115, PDF 북마크)
│   ├── 사례집/            NNN_<제목>.md            NNN = 문제 번호(001~161)
│   ├── 추록/ · 정오표/    검색용 (상자 배치가 섞인다 — 원본 쪽을 함께 본다)
├── 노트/                  ← 결과물
│   └── 목차집/            CH<장>_<장제목>.md  손으로 쓴다
└── 작업/
    ├── references/        목차집.md(작성 원칙) · 정오.md(추록·정오표 대응) · 기본서목차.tsv
    └── 도구/              경로.py · 목차재료.py · 목차표.py
```

## 어디서 무엇을 하나

| 일 | 어디서 |
|---|---|
| PDF → 마크다운 | **사장님 PC.** 원본 PDF가 거기 있다 |
| 절 점검·매핑 | 어느 쪽이든. `convert --book patent …` |
| 목차표 다시 뽑기 | 사장님 PC. `작업/도구/목차표.py <기본서.pdf>` |
| 목차집 | 리포를 읽는 세션. `작업/references/목차집.md` 를 따른다 |

변환 결과가 바뀌면 `출력/` 을 다시 올려야 한다. 절이 바뀌면 노트의 목차도
바뀌기 때문이다. **재변환 → 올리기 → 노트** 순서를 지킨다.

## 목차집을 쓰기 전에 읽을 것

1. `작업/references/목차집.md` — 작성 원칙 (민소법 목차집과 같은 형식)
2. `작업/references/정오.md` — 추록·정오표로 바뀐 논점·문제
3. `../book2md/OUTPUT.md` — **변환물의 한계.** 무엇을 믿고 무엇을 의심할지

변환물에서 알아 둘 것: 스캔 + OCR 이라 본문 논점 제목·사건번호가 자주 깨진다
(「십판」「91D!540」). 파일 경계와 제목은 북마크(+ `config-patent.yaml` 의 `outline_patch`)로
잡았으므로 믿어도 되고, 사건번호는 목차집에 쓰지 않는다.
