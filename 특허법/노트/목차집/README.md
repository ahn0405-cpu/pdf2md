# 목차집 (특허법)

논점마다 **핵심 · 의의 · 개조식 목차 · 사례** 를 장(CHAPTER) 단위로 묶은 회독용 문서다(도쓰 암기장 양식).
시험장에서 목차를 세우고(사례), 판례 입장과 두문자를 떠올리는(개조식 목차) 데 쓴다.
민소법 목차집(`../../../민소법/노트/목차집/`)과 같은 형식이다.

**손으로 쓴다.** 생성기가 없으므로 고치거나 메모를 더해도 덮어써지지 않는다.

| 칸 | 무엇 | 근거 |
|---|---|---|
| 핵심 | 논점을 꿰는 물음·명제 한 줄 | 기본서 1. 의의 및 취지 |
| 의의 | 정의 + 취지 한 줄 | 기본서 1. 의의 및 취지 |
| 개조식 목차 | 쟁점의 물음 · 학설 · 판례 요건과 결론(判 / 특허법원) · 심사기준 · 두문자. 사건번호는 쓰지 않는다 | 기본서 원문 |
| 사례로 나오면 | 문제 유형마다 답안 큰 목차 순서와 설문 배점 | 사례집 **설문·배점과 답안 목차 제목만** |

`〔추록〕` `〔정오〕` 가 붙은 줄은 기본서 9판 1차 추록·사례집 5판 정오표로 바뀐 내용이다.

작성 원칙은 `../../작업/references/목차집.md` 에 있다.

```bash
cd 특허법/작업/도구
python3 목차재료.py 2-07       # 쓸 재료 — 기본서 뼈대·의의·학설 + 사례집 답안 목차(사례 줄)
python3 목차재료.py --검사     # 쓴 장 안에서 아직 없는 논점 · 기본서에 없는 두문자
```
