# 📄 PDF → Markdown 변환기 (웹)

여러 개의 PDF를 한 번에 올려 **원본 서식을 최대한 유지한 Markdown**으로 바꾸는 로컬 웹앱이다.
파일은 브라우저 → 로컬 서버로만 오가고 외부로 전송되지 않는다.

## 설치 · 실행

```bash
pip install -r requirements.txt
python app.py            # http://127.0.0.1:5000
```

옵션: `--host 0.0.0.0 --port 8080` (같은 네트워크의 다른 기기에서 접속할 때), `--debug`.

## 웹 UI

- **여러 파일 선택**: 파일 선택 대화상자에서 다중 선택하거나, 드래그&드롭(**폴더째** 끌어와도 하위 PDF를 모두 수집).
- 파일마다 진행 상태 · 쪽수 · 인식한 제목/표/이미지 수 · 경고를 표시한다.
- 오른쪽에서 **미리보기(렌더링) / 마크다운 원문**을 전환해 결과를 확인한다.
- 내려받기: 개별 `.md`, 이미지까지 묶은 개별 `.zip`, 전체 결과 `markdown.zip`.
- 옵션은 브라우저에 저장되어 다음 실행 때 그대로 쓰인다.

## 서식 보존 방식

| 원본 요소 | 변환 결과 | 판정 근거 |
|---|---|---|
| 제목 | `#`~`######` | PDF 북마크(TOC) 우선, 없으면 본문 대비 글자 크기 순위. 굵은 번호형 제목(`1.1`, `제3조`) 보조 인식 |
| 문단 | 한 문단으로 병합 | 줄 간격·좌측 정렬이 이어지는 블록을 잇고, 간격이 벌어지면 문단을 나눔 |
| 줄바꿈 | 자연스럽게 연결 | 영문은 공백, 한자·가나는 붙임, 한글은 어절 공백 복원, `-` 로 끊긴 단어는 병합 |
| 목록 | `-` / `1.` + 중첩 | 글머리표(`•‣▪·` 등)·번호(`1.`, `(1)`, `가.`, `①`)를 인식하고, 문서에 실제로 나타난 들여쓰기 위치를 군집화해 단계를 매김 |
| 표 | 마크다운 표 / HTML 표 / 고정폭 | 표 영역의 텍스트는 본문에서 제외해 중복을 막음 |
| 굵게·기울임·고정폭 | `**`, `*`, `` ` `` | 글꼴 플래그 + 글꼴 이름(`Bold`, `Oblique`, `Mono` 등) |
| 하이퍼링크 | `[텍스트](주소)` | PDF 링크 주석 영역과 글자 상자의 겹침 |
| 이미지 | 파일 추출 / base64 삽입 | 원본 위치 순서대로 삽입. 구분선 크기의 자잘한 이미지는 제외 |
| 2단 조판 | 왼쪽 단 → 오른쪽 단 순서 | 전폭 요소로 밴드를 나눈 뒤 세로 여백(gutter)을 찾아 단을 분리 |
| 머리말·꼬리말 | 제거 | 페이지 위/아래 10% 영역에서 절반 이상 페이지에 반복되는 문구, 숫자만 있는 쪽번호 |

## 옵션

| 옵션 | 기본 | 설명 |
|---|---|---|
| 제목 자동 인식 / PDF 북마크 사용 | 켬 | 끄면 모든 줄을 본문으로 처리 |
| 목록 인식 | 켬 | |
| 굵게/기울임/고정폭 | 켬 | 끄면 순수 텍스트 |
| 하이퍼링크 보존 | 켬 | |
| 다단 레이아웃 복원 | 켬 | 단 인식이 오작동하면 끄고 위→아래 순서로 |
| 머리말/꼬리말 제거 | 켬 | |
| 줄바꿈 하이픈 병합 | 켬 | |
| 페이지 구분선 / 페이지 주석 | 끔 | `---`, `<!-- page N -->` |
| YAML 머리말 | 끔 | 제목·작성자·출처·쪽수 |
| 표 처리 | 마크다운 표 | HTML 표는 셀 안 줄바꿈에 유리 |
| 이미지 처리 | 파일로 추출 | base64는 단일 `.md`로 끝내고 싶을 때 |

## 명령줄로도 사용

```bash
python cli.py 파일1.pdf 파일2.pdf -o out/
python cli.py doc.pdf --tables html --images base64 --page-separator
```

## 알아둘 점

- **스캔 PDF(텍스트 레이어 없음)** 는 추출할 글자가 없다. 경고를 표시하며, OCR을 먼저 돌려야 한다.
- **암호가 걸린 PDF**는 열 수 없다는 오류를 낸다.
- 도형으로 그린 차트·다이어그램은 이미지가 아니라 벡터라서 추출되지 않는다.
- PDF 엔진(MuPDF)이 프로세스당 하나의 컨텍스트를 쓰므로 변환은 **한 건씩 직렬**로 처리된다.
- 변환 결과는 서버 메모리에 최대 1시간(`PDF2MD_TTL`), 200건(`PDF2MD_JOB_LIMIT`)까지만 보관된다.
  업로드 크기 상한은 `PDF2MD_MAX_MB`(기본 200MB).
