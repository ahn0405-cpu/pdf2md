# 📄 PDF → Markdown 변환기

여러 개의 PDF를 한 번에 올려 **원본 서식을 최대한 유지한 Markdown**으로 바꾼다.

**파일 하나로 끝난다.** `dist/pdf2md.html` 을 크롬에서 열면 그게 전부다.
설치도, 서버도, 인터넷도 필요 없다.

## 쓰는 법

`dist/pdf2md.html` 을 내려받아 크롬에서 연다. 끝이다.
(바탕화면에 두고 더블클릭해도 되고, USB에 담아 다른 PC에서 열어도 된다.)

- **여러 파일 선택**: 파일 선택창에서 여러 개를 고르거나, 드래그&드롭(**폴더째** 끌어오면 하위 PDF를 모두 수집).
- 파일마다 진행 상태 · 쪽수 · 인식한 제목/표/이미지 수 · 경고를 보여준다.
- 오른쪽에서 **미리보기(렌더링) / 마크다운 원문**을 전환해 결과를 확인한다.
- 내려받기: 목록의 **⬇** 로 그 파일만 (이미지가 있으면 `.zip`, 없으면 `.md`),
  **각각 저장** 으로 완료된 것을 하나씩 따로, **전체 ZIP** 으로 한 덩어리.
  미리보기 위쪽에서 `.md` / `.zip` 을 직접 고를 수도 있다.
- 옵션은 브라우저에 저장되어 다음에 열 때 그대로 쓰인다.

### 파일은 밖으로 나가지 않는다

PDF를 서버에 올리는 방식이 아니다. PDF 엔진(MuPDF)이 WebAssembly로 페이지 안에
들어 있어서 **변환이 전부 브라우저 탭 안에서** 일어난다. 네트워크 요청이 아예 발생하지
않는 것을 자동 테스트로 확인한다. 밖으로 내보내면 안 되는 자료도 안심하고 쓸 수 있다.

## 서식 보존 방식

MuPDF에서 글꼴·크기·굵기·좌표를 글자 단위로 받아 판단한다.

| 원본 요소 | 변환 결과 | 판정 근거 |
|---|---|---|
| 제목 | `#`~`######` | PDF 북마크(목차) 우선, 없으면 본문 대비 글자 크기 순위. 굵은 번호형 제목(`1.1`, `제3조`) 보조 인식 |
| 문단 | 한 문단으로 병합 | 줄 간격·좌측 정렬이 이어지는 블록을 잇고, 간격이 벌어지면 문단을 나눔 |
| 줄바꿈 | 자연스럽게 연결 | 영문은 공백, 한자·가나는 붙임, 한글은 어절 공백 복원, `-` 로 끊긴 단어는 병합 |
| 목록 | `-` / `1.` + 중첩 | 글머리표(`•‣▪·` 등)·번호(`1.`, `(1)`, `가.`, `①`)를 인식하고, 문서에 실제로 나타난 들여쓰기 위치를 군집화해 단계를 매김 |
| 표 | 마크다운 표 / HTML 표 / 고정폭 | 페이지에 그려진 **괘선(벡터 경로)** 을 모아 격자를 복원하고, 글자를 좌표로 각 칸에 배치 |
| 굵게·기울임·고정폭 | `**`, `*`, `` ` `` | 글꼴의 굵게/기울임/고정폭 속성 |
| 하이퍼링크 | `[텍스트](주소)` | PDF 링크 주석 영역과 글자 상자의 겹침 |
| 이미지 | 파일 추출 / base64 삽입 | 원본 위치 순서대로. 페이지 위/아래에서 쪽마다 되풀이되는 로고·직인·바코드는 본문이 아니라고 보고 뺀다 |
| 코드 블록 | 코드 펜스 | 고정폭 글꼴 구간. 들여쓰기는 x좌표에서, 사이의 빈 줄은 줄 간격에서 복원 |
| 2단 조판 | 왼쪽 단 → 오른쪽 단 순서 | 전폭 요소로 밴드를 나눈 뒤 세로 여백(gutter)을 찾아 단을 분리 |
| 머리말·꼬리말 | 제거 | 페이지 위/아래 10%에서 절반 이상 페이지에 반복되고, **그 가로줄을 혼자 쓰는** 문구. 숫자만 있는 쪽번호. 본문보다 큰 글자, 한 구역에 세 줄 넘게 걸린 것, 문장으로 끝나는 것은 본문으로 보고 남긴다 |

## 옵션

| 옵션 | 기본 | 설명 |
|---|---|---|
| 제목 자동 인식 / PDF 북마크 사용 | 켬 | 끄면 모든 줄을 본문으로 처리 |
| 목록 인식 | 켬 | |
| 굵게/기울임/고정폭 | 켬 | 끄면 순수 텍스트 |
| 하이퍼링크 보존 | 켬 | |
| 다단 레이아웃 복원 | 켬 | 단 인식이 오작동하면 끄고 위→아래 순서로 |
| 머리말/꼬리말 제거 | 켬 | 반복되는 제목줄·쪽번호와, 가장자리에서 되풀이되는 로고·바코드 이미지 |
| 끝의 안내문 제거 | 끔 | 「`<< 안내 >>`」 같은 줄부터 문서 끝까지 버린다. 관공서·특허 서식의 제출 절차 안내용 |
| 줄바꿈 하이픈 병합 | 켬 | |
| 페이지 구분선 / 페이지 주석 | 끔 | `---`, `<!-- page N -->` |
| YAML 머리말 | 끔 | 제목·작성자·출처·쪽수 |
| 표 처리 | 마크다운 표 | HTML 표는 셀 안 줄바꿈에 유리 |
| 이미지 처리 | 파일로 추출 | base64는 단일 `.md`로 끝내고 싶을 때 |

옵션을 바꾸면 이미 변환한 파일도 다시 변환할 수 있게 대기 상태로 돌아간다.

## 알아둘 점

- **스캔 PDF(텍스트 레이어 없음)** 는 추출할 글자가 없다. 경고를 표시하며, OCR을 먼저 돌려야 한다.
- **암호가 걸린 PDF**는 열 수 없다는 오류를 낸다.
- 도형으로 그린 차트·다이어그램은 이미지가 아니라 벡터라서 추출되지 않는다.
- 첫 변환 때 WebAssembly 초기화에 잠깐(1초 안팎) 걸린다. 이후는 빠르다
  (3쪽 0.05초, 10쪽 0.10초 수준).
- 위쪽 여백이 아주 좁은 문서에서 본문 첫 줄이 머리말로 오인될 수 있다.
  그럴 때는 **머리말/꼬리말 제거** 옵션을 끈다.
- 크롬 기준으로 만들었다. ZIP 압축에 `CompressionStream` 을 쓴다.

## 개발

```bash
npm install
npm test         # 회귀 테스트 39건
npm run build    # dist/pdf2md.html 생성
```

| 경로 | 역할 |
|---|---|
| `src/converter.js` | 변환 로직 (레이아웃 분석 · Markdown 생성) |
| `src/app.js` | UI |
| `src/markdown.js` | 미리보기용 소형 마크다운 렌더러 |
| `src/zip.js` | 브라우저에서 ZIP 만들기 |
| `src/index.html`, `src/style.css` | 화면 |
| `build.mjs` | 전부를 단일 HTML로 묶는다 (WASM은 gzip 후 base64로 인라인) |
| `test/run.mjs` | 회귀 테스트 |
| `test/fixtures/` | 테스트용 PDF (`test/make-fixtures.py` 로 생성, PyMuPDF 필요) |

개발 중에는 정적 서버로 `src/` 를 열어도 된다(`npx http-server src`).
이때는 `node_modules` 의 mupdf를 그대로 쓴다.
