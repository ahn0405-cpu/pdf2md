# pdf2md — 변리사 2차 교재 단권화

변리사 2차 교재 PDF를 마크다운으로 바꾸고, 그것으로 과목별 **단권화 이해노트**와
**암기노트**를 만든다. 작업 규칙은 [CLAUDE.md](CLAUDE.md) 에 있다.

| 폴더 | 무엇 |
|---|---|
| [민소법/](민소법/) | 민사소송법 — 진행 중. 노트는 `민소법/노트/` |
| [특허법/](특허법/) | 특허법 — 변환 진단만 있다 |
| [book2md/](book2md/) | 교재 PDF → 마크다운 변환기 (Python) |
| [web/](web/) | 일반 PDF → 마크다운 브라우저 도구 `pdf2md.html` (단권화와 무관) |

과목 폴더는 모두 같은 틀이다.

```
<과목>/
├── 출력/     소스 — book2md 변환 결과 (기본서 · 사례집)
├── 노트/     결과물 — 단권화 · 암기노트
└── 작업/     규칙(SKILL.md) · 현황 · 참조 자료 · 도구
```
