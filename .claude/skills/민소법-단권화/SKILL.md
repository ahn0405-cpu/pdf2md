# 민소법 단권화

**이 파일에는 기준이 없다.** 기준은 리포 안에 있고, 아래 파일들을 **먼저 읽어야** 한다.

```
민소법/단권화/SKILL.md              ← 작성 기준. 1000줄 남짓. 전부 읽는다
민소법/단권화/작업현황.md             ← 어디까지 했고 무엇이 남았나
민소법/단권화/references/소스결함.md   ← 변환물의 결함 유형과 탐지 신호
민소법/단권화/references/확인목록.md   ← 원본 PDF 대조 대기 목록
민소법/단권화/samples/046_일부청구.md  ← 참조 샘플
```

**규칙과 샘플이 충돌하면 샘플을 우선한다.**

## 왜 표지만 두는가

기준이 `references/`·`samples/` 를 함께 봐야 성립하므로 이 디렉터리에 복사해 두면
두 판본이 갈라진다. 실제로 계정에 동기화된 같은 이름의 스킬이 그렇게 낡아
**758줄에서 멈춘 채 참조 파일도 없이** 남아 있다.
그 판본이 아니라 **리포의 것**이 기준이다.

## 작업 디렉터리

스크립트는 `민소법/단권화` 에서 돌린다. 어떤 스크립트가 무엇을 하는지는
리포 루트의 `CLAUDE.md` 에 표로 있다.

```bash
cd 민소법/단권화
python3 전말검사.py                  # 지금 남은 결함
python3 전말덤프.py output/058_*.md  # 한 파일 고칠 재료
```
