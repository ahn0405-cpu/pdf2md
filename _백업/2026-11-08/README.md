# pdf2md — 변리사 2차 교재 단권화

변리사 2차 교재 PDF를 마크다운으로 바꾸고, 그것으로 과목별 **단권화 이해노트 · 목차집 · 암기노트 · 빈칸채우기**를 만든다.

**무엇을 어떻게 하는지는 [사용법.md](사용법.md)** 에 모았다. Claude 가 지키는 규칙은 [CLAUDE.md](CLAUDE.md).

| 폴더 | 무엇 |
|---|---|
| [민소법/](민소법/) | 민사소송법 — 단권화 노트 001～140, 목차집 18장, 암기노트·빈칸채우기(CH08 부터) |
| [특허법/](특허법/) | 특허법 — 목차집 9장 |
| [book2md/](book2md/) | 교재 PDF → 마크다운 변환기 (Python) |
| [web/](web/) | 일반 PDF → 마크다운 브라우저 도구 `pdf2md.html` (단권화와 무관) |
| `superthread.json` | Superthread 에 무엇을 어느 스페이스로 올리는지 (`../superthread/upload.py` 가 읽는다) |

과목 폴더는 모두 같은 틀이다.

```
<과목>/
├── 출력/     소스 — book2md 변환 결과 (기본서 · 사례집). 손대지 않는다
├── 노트/     결과물 — 단권화 · 목차집 · 암기노트 · 빈칸채우기 (특허법은 목차집만)
└── 작업/     규칙 · 현황 · 참조 자료 · 도구
```
