# 목차집

논점마다 **핵심 · 의의 · 개조식 목차** 를 장(CHAPTER) 단위로 묶은 문서다(도쓰 암기장 양식).
**기본서 내용과 순서의 요약**이다 — 판례 입장과 두문자를 기본서 순서로 떠올리는 데 쓴다.

노트 네 층(단권화·목차집·암기노트·빈칸채우기)이 어떻게 나뉘는지는 [`민소법/README.md`](../../README.md#노트의-네-층), 할 일별 명령은 루트 [사용법.md](../../../사용법.md).

CH08 밖의 장에는 논점 끝에 옛 `▸ 사례로 나오면` 블록이 남아 있다(그 장의 암기노트를 쓸 때 옮긴다).
목차집에 붙인 📝 메모는 목차집에만 있다.

**손으로 쓴다.** 생성기가 없으므로 고치거나 메모를 더해도 덮어써지지 않는다.

| 칸 | 무엇 | 근거 |
|---|---|---|
| 핵심 | 논점을 꿰는 물음·명제 한 줄 | 노트 I. 의의 해설 |
| 의의 | 정의 + 취지 한 줄 | 기본서 I. 의의 |
| 개조식 목차 | 쟁점의 물음 · 학설(근거, 判 굵게) · 판례 요건과 결론(判) · 두문자. 사건번호는 쓰지 않는다 | 기본서 원문 (判 위치는 노트로 확인) |

작성 원칙은 `../../작업/references/목차집.md` 에 있다.

```bash
cd 민소법/작업/도구
python3 목차재료.py 068        # 쓸 재료 — 노트 목차·의의·학설·사례집 답안 목차(암기노트 재료)
python3 목차재료.py --검사     # 아직 없는 논점 · 노트에 없는 두문자 · 빠진 사례 번호
```
