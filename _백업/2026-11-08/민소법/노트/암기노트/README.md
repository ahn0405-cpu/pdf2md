# 암기노트

**시험장에 들고 갈 한 권**이다. 사례집 문제를 **답안 순서**로 묶은 뼈대(단계 · 배점 · 두음)와,
단계마다 답안에 쓸 **압축 문장**(사례집 모범답안을 줄인 것)을 장(CHAPTER) 단위로 둔다. **굵은 말**이 채점 키워드다.

노트 네 층이 어떻게 나뉘는지는 [`민소법/README.md`](../../README.md#노트의-네-층), 할 일별 명령은 루트 [사용법.md](../../../사용법.md).

**손으로 쓴다.** 고쳐도 덮어써지지 않는다. 작성 원칙은 `../../작업/references/암기노트.md`.
연습판 `../빈칸채우기/` 는 이 파일에서 뽑으므로, 고친 뒤 다시 뽑는다.

```bash
cd 민소법/작업/도구
python 빈칸채우기.py 08         # 연습판 다시 뽑기
python 빈칸채우기.py --검사 08  # 문장 없는 단계 · 15자 넘는 굵은 말
python 목차재료.py 066          # 쓸 재료 — 「4 사례집 답안 목차」(어느 문제·배점). 문장은 출력/사례집 의 모범답안에서
python 목차재료.py --검사       # 사례 번호 빠짐 0
```

- `〔기본서〕` 가 붙은 줄은 사례집 모범답안에 없어 단권화 노트(기본서)에서 채운 것이다. 나머지는 사례집 모범답안을 압축한 것.
- 논점 끝 `<!-- 확인: … -->` 는 Claude 가 사용자 판단이 필요한 자리에만 남긴다(규칙으로 정한 것에는 달지 않는다). 있으면 `빈칸채우기.py --검사 08` 이 모아 보여 준다.
- 문제 번호는 원본 사례집으로 확인했다(2026-10-20). 변환물에서 번호가 깨진 문제는 원본 PDF 그림으로 확정한다.
- 지금 있는 장은 **CH08** 하나다. CH08 의 template 31개 모두에 압축 문장이 있다(052 2026-10-20 시범, 053～075 2026-10-21).
- 다른 장은 목차집 논점 끝 `▸ 사례로 나오면` 블록(옛 형식)에 사례 줄이 있다. 그 장을 쓸 때 옮긴다.
- 1위 논점이 다른 장인 문제는 `→ 076 재판상 자백 (CH09)` 처럼 가리킴만 두었다. 그 장을 쓸 때 template 을 만든다.
