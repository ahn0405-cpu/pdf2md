# 안쓰 — 나만의 노트

`도쓰/` 는 원문 보관(도쓰 PDF + 첫 변환 md, 고치지 않는다). **내가 만들고 고치는 노트는 모두 여기**에 둔다.

```
안쓰/
├── 민소법/
│   └── 도쓰/        목차 · 암기장 · 자료   ← 도쓰 민소 md 복사본. 판례를 덧붙여 키운다
├── 특허법/
│   ├── 도쓰/        암기장 · 자료          ← 도쓰 특허 md 복사본
│   ├── 박형준GS/    암기장 · 자료 · 빈칸채우기   ← 박형준 기초 GS + 준특허법(기본서)으로 만드는 노트
│   ├── 도구/        박형준GS 를 만드는 도구
│   └── 원본/        박형준 PDF 둘 — 커밋하지 않는다(194MB·236MB). PC 마다 따로 옮긴다
└── _work/           도구의 중간 산물 (커밋하지 않는다)
```

## 덧붙이는 규칙 〔+〕 — 도쓰 복사본에서

도쓰 원문과 내가 넣은 것을 가르려고, **덧붙이거나 고친 줄 끝에 `〔+〕`** 를 단다. 지운 것은 `<!-- 지움: … -->` 로 남긴다.
`〔+〕` 를 검색하면 내가 넣은 것만 모아 볼 수 있다. 박형준GS 는 처음부터 내 노트라 `〔+〕` 를 달지 않는다.

- **판례 추가** — 암기장(뼈대)에 한 줄 + 자료(판시)에 한 문단, 같은 두문자로 짝짓는다.
- **논점 추가** — 목차 · 암기장 · 자료 세 곳 같은 순서 자리에.
- 과목별 자세한 방법과 예는 각 폴더 README.
