# 안쓰 · 민소법

`도쓰/` 의 세 파일은 도쓰 민소 md 의 복사본이다(2026-11-08). 여기서 판례·목차를 덧붙여 내 노트로 키운다.

## 세 파일의 관계

| 파일 | 역할 | 실측(복사 때) |
|---|---|---|
| `목차.md` | 차례 — 편 → 장 → `<논점>` | 논점 41 |
| `암기장.md` | **뼈대** — 논점별 template(답안 목차) · 쟁점 `[..]` · 학설 결론 · 두문자 | 논점 42 · template 68 · 두문자 416 |
| `자료.md` | **살** — 암기장의 두문자 하나하나를 판시·학설·검토 문장으로 | 논점 39 · 두문자 365 (363 이 암기장과 같다) |

연결 열쇠는 **두문자 + 쟁점 이름**이다.

```
암기장   (3) 判例 [추완항소 부적법 주장] **(일신모피)**
자료     [추완항소 부적법 주장] **(일신모피)**
         判例 i) 당사자 일방이 과거에 **일정**한 태도를 … **신뢰**하고 … **모순**되는 … **피고** 자신이 …
```

암기장에만 있는 두문자(31개)는 판시 없이 암기장 안에서 끝나는 것(의의·요건 나열 등)이다.

## 판례를 덧붙이는 법 — 예: 토지관할

판례 하나 = **암기장 한 줄 + 자료 한 문단**, 같은 두문자로 짝짓는다. 넣거나 고친 줄 끝에 `〔+〕`.

암기장 — 원문 한 줄을 보통·특별재판적으로 가르고, 그 아래 판례 줄을 넣는다.
```
토지관할 (보특관경)
- 보통재판적: 3, 5①② 〔+〕
  - [쟁점 이름] 判 **(두문자)** 〔+〕
- 특별재판적: 7, 8후단, 11, 12, 18, 20, 21 〔+〕
  - [쟁점 이름] 判 **(두문자)** 〔+〕
- 관련재판적 (25①②)
```

자료 — `<관할>` 에는 「사물관할 토지관할」 이름표만 있고 토지관할 판례가 없다. 그 이름표와 「합의관할」 사이에:
```
**토지관할** 〔+〕

[쟁점 이름] **(두문자)** 〔+〕

判例 i) **가**… ii) **나**… 〔+〕
```
두문자 글자로 시작하는 낱말을 굵게 한다(원문과 같은 방식 — 나중에 빈칸 키가 된다).

- **논점 추가** — `목차.md` `- <새 논점> 〔+〕` · `암기장.md` `#### <새 논점> 〔+〕` · `자료.md` `#### <새 논점> 〔+〕` 를 같은 순서 자리에.
- Claude 에게 「토지관할 보통재판적에 ○○ 판례 넣어 줘」처럼 쟁점과 판례(사건번호만이라도)를 주면, 판시를 찾아 확인받고 두 파일에 함께 넣는다.
  두문자를 안 주면 판시 핵심어로 제안해 확인받는다.
- 세 파일의 어긋남(짝 없는 두문자, 논점 순서)을 잡는 `연결검사.py` 는 판례를 실제로 넣기 시작할 때 만든다.
