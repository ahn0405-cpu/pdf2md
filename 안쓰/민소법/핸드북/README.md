## 도쓰와 맞물리는 방식

- **핸드북 → 도쓰**: 암기장 사례 머리 아래 「도쓰 `<관할>` 합의관할 … **(지변정)**」 — 같은 논점·두문자.
- **도쓰 → 핸드북**: `../도쓰/[민소법] 안쓰 도쓰 암기장.md` 해당 논점 아래 `→ 핸드북 [사례 2-5-3] … p.20 〔+〕`.
- 짝 찾기는 `../도구/대응.py 2-5-3`(사례 → 도쓰 블록) · `대응.py --논점 관할`(도쓰 논점 → 사례).

## 빈칸 고르는 순서 (핸드북 본문엔 형광펜이 없다)

1. 같은 판례가 도쓰 자료에 있으면 **도쓰의 굵은 두문자 낱말** — `〔도쓰 (지변정)〕`
2. 책이 소제목에 단 두음 `[암 …]` 이 있으면 그 글자로 시작하는 낱말 — `〔암 1임특특〕`
3. 위가 없어도 **★ · 표준판례(책의 \*)** 문장이면 핵심어 1～3개 — `<!-- 핵심어 -->`
4. 기준 밖이어도 중요한 판례(전원합의체, 사안을 가르는 판례)면 핵심어 1～3개 — `<!-- 핵심어 — 중요 판례 -->`
5. 그 밖엔 빈칸 없이 — `<!-- … 빈칸 없음 -->`

`<도쓰>` 칸은 도쓰 원문의 굵은 말이 그대로 빈칸이 된다.

책의 강조 표시(머리말 p.3): ★ = 반드시 이해·암기 · 판례번호 앞 \* · [표준판례] = 표준판례 · 高 = 고득점 요령. 차례 쪽의 노란 형광은 무시(사용자).

## 고친 뒤

먼저 형식 점검 — 「오」 가 0 이 될 때까지 고친다(VS Code 미리보기에서 줄이 붙거나 글자 크기가 들쭉날쭉한 곳):

```bash
python ../도구/형식점검.py "[민소법] 안쓰 핸드북 암기장 제2편.md" "[민소법] 안쓰 핸드북 자료 제2편.md"
```

머리 꼴: `# 편` → `## 장` → `### 2-5 관할`(주제) → `#### <도쓰>` · `#### [사례 …]` → `##### 설문(n)`. 자료의 답안 소제목은 머리가 아니라 `▸ …` 본문 줄(굵게 쓰면 빈칸이 된다).

자료를 고치면 빈칸채우기·빈칸정답·플래시카드를 다시 뽑는다(손으로 고치지 않는다):

```bash
cd 안쓰/특허법/도구
python 빈칸채우기.py --검사 --번호머리 5 --자료 "../../민소법/핸드북/[민소법] 안쓰 핸드북 자료 제2편.md"
python 빈칸채우기.py        --번호머리 5 --자료 "../../민소법/핸드북/[민소법] 안쓰 핸드북 자료 제2편.md"
```

## 재료

- `../OCR/핸드북/제N편_*.md` — 핸드북 OCR 원문(교정 전). 사례마다 `## [사례 …]`, 쪽 `<!-- p.12 · pdf 14 -->`.
- 쪽 그림: `python ../../특허법/도구/쪽그림.py 14 23 --pdf "../원본/2024 핸드북 진도별 민소법 기출문제_OCR.pdf" --out ../../_work/핸드북/그림`
  (이 책은 쪽이 작아 잘림이 있으면 전체 쪽으로 다시 뜬다). 스캔 자체가 깨진 글자(「□1□」「七질적」)가 있어 조문은 법령 원문으로 채우고 `<!-- 조문 원문 -->`.
- 원본 PDF 는 `../원본/`(커밋 안 함). 쪽 = 책 쪽 = pdf 쪽 − 2.
