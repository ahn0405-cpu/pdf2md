## 규칙 (결정된 것 — README 「빈칸 고르는 순서」)

- 핸드북과 도쓰는 **서로 가리킨다**: 암기장 사례 머리 아래 「도쓰 `<논점>` … **(두문자)**」, 도쓰 복사본 논점 아래 `→ 핸드북 [사례 …] p.N 〔+〕`.
- 빈칸: ① 같은 판례가 도쓰에 있으면 도쓰의 굵은 두문자 낱말 〔도쓰 …〕 ② 책이 소제목에 단 `[암 …]` 두음의 낱말 〔암 …〕 ③ ★·표준판례(책의 *) 문장이면 핵심어 1～3개 `<!-- 핵심어 -->` ④ 셋 다 아니면 빈칸 없이 `<!-- … 빈칸 없음 -->`.
- 책의 강조: ★ 반드시 암기 · 판례번호 앞 * · [표준판례] = 표준판례 · 高 고득점. **차례 쪽의 노란 형광은 무시.** 기출 출처(특히 理=변리사)가 중요.
- 사건번호는 법령 DB(`search_decisions`)로 확인한 것만. 스캔이 깨진 조문은 법령 원문으로 채우고 `<!-- 조문 원문 -->`.
- 파일 이름 `[민소법] 안쓰 핸드북 …`. 정답은 따로. 회차·사례 묶음마다 커밋, push 는 사용자.
