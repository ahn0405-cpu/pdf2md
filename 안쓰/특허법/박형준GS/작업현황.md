## 규칙 (사용자 결정 — README 「빈칸 = GS 형광펜」)

- 목표: 수석합격자처럼 **GS 답안을 외운다**.
- **빈칸 = GS 판례(살구)·조문(연두)·취지(하늘) 형광펜 구절 그대로.** 사안(보라)은 빈칸 아님. Claude 가 빈칸을 고르지 않는다.
- 암기장 = 지문·물음(인용) + 설문마다 **키워드 상자**(굵게) · 기본서 절·쪽 · 답안 목차 · 사안·결론 한 줄.
- 자료 = 판례·조문·취지 문장만. 사안(보라)뿐인 문장·문제는 넣지 않는다(암기장에만).
- 판례 문장은 `判例 ` 로 시작. GS 키워드 상자에 두음이 있으면(「출기통선대」) 문장 끝에 〔…〕 힌트.
- 사건번호는 4회차부터 달지 않았다(법령 DB 로 확인한 것만 단다는 규칙 — 사용자가 원하면 나중에).
- 파일 이름 `[특허법] 안쓰 GS …`. 빈칸정답은 따로(`빈칸채우기.py` 가 둘 다 뽑는다).
- 회차를 끝내면 **커밋**(한국어, 무엇을 왜). push 는 사용자가 한다(자동 권한 검사가 막는다).

## 한 회차를 만드는 순서 (예: 10회차)

```bash
cd 안쓰/특허법/도구
python 쪽그림.py 89 102                 # 1. 쪽 그림 → 안쓰/_work/박형준/그림/h089.png…  (Read 로 본다)
python 대응.py 10                       # 2. GS 쪽마다 기본서 절·쪽 후보(8-gram)
python gs_초안.py 10 --보기 > ../../_work/박형준/v10.txt   # 3. OCR + 형광펜 {판 조 취 사} 구절
```

4. `v10.txt` 를 읽고, OCR 이 깨진 쪽과 **지문 쪽은 반드시 그림으로** 확인한다. 형광펜 범위는 `{판 …}` `{조 …}` `{취 …}` 그대로 `**굵게**`.
5. 초고를 **Write 도구로** `안쓰/_work/박형준/초고/10_암기장.md` · `10_자료.md` 에 쓴다(첫 줄 빈 줄, `## 10회차 문제-1 (30점)` 부터).
   셸 히어독으로 쓰지 않는다 — 긴 한글 마크다운에서 깨졌다.
6. 붙이고 검사하고 뽑고 커밋:

```bash
python 붙이기.py 10
python 빈칸채우기.py --검사      # 0건이어야
python 빈칸채우기.py
```

- 기본서 절 이름은 `../OCR/준특허법/NN장_*.md` 의 `## 2.6.9 …` 머리, 또는 `대응.py` 후보를 차례로 맞춘다. 차례 OCR 에 없는 절(예 4.2.5 균등론)은 차례 원문 기준.
- 같은 법리가 앞 회차에 나왔어도 GS 가 다시 칠했으면 그 회차 자료에 다시 쓴다(설문 단위 연습). 다만 같은 회차 안에서 문제 하나가 다른 문제를 통째로 되풀이하면 암기장에만(9회차 문제-3 예).
