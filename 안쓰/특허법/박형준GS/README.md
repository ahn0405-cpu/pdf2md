# 박형준 기초 GS 노트

박형준 「바주카포 동차용 정리 자료」 기초 GS+ 3～18회(보충문제 포함)를 외우기 위한 노트.
목표: 수석합격자처럼 **GS 답안을 그대로 외운다** — 답안 목차는 암기장으로, 답안에 쓸 판례·조문·취지 문장은 빈칸채우기로.

| 파일 | 무엇 | 만드는 법 |
|---|---|---|
| `[특허법] 안쓰 GS 암기장.md` | 문제마다 지문·물음 → 설문마다 **키워드 상자** · 기본서 자리 · **답안 목차(template)** · 사안 한 줄 | 손으로 (GS 쪽 그림 보고) |
| `[특허법] 안쓰 GS 자료.md` | 설문마다 답안에 쓸 **판례 · 조문 · 취지** 문장(GS 원문). **굵은 말 = 빈칸** | 손으로 |
| `[특허법] 안쓰 GS 빈칸채우기.md` | 자료의 굵은 말을 정답 글자 수만큼 (1 ＿＿＿ ＿)로 가린 연습판(띄어쓰기 그대로) — **정답 없음** | `../도구/빈칸채우기.py` 가 뽑는다 |
| `[특허법] 안쓰 GS 빈칸정답.md` | 빈칸채우기의 정답, 같은 문제·설문 머리 아래 | 〃 (손으로 고치지 않는다) |
| `[특허법] 안쓰 GS 플래시카드.txt` | 휴대폰 앱 **Flashcards Deluxe** 덱 — 소제목(`####`) 하나 = 카드 한 장. 앞 = 빈칸, 뒤 = 정답 굵게. 분류1 = 회차·문제, 분류2 = 설문 | 〃 |

```
암기장(뼈대: 목차·키워드)  ──같은 문제·설문──▶  자료(외울 문장, 굵은 말)  ──빈칸채우기.py──▶  빈칸채우기 + 빈칸정답 + 플래시카드
```

## 휴대폰으로 (Flashcards Deluxe)

`.txt` 는 탭 구분 UTF-8 — 파일 이름이 덱 이름이 된다. 옮기는 길 하나만 고르면 된다:

- **Dropbox**: `Flashcards Deluxe` 폴더에 `.txt` 를 넣고, 앱 덱 화면 **+ → Dropbox** 에서 고른다.
- **안드로이드**: 파일을 앱의 파일 폴더에 복사한 뒤 덱 화면 **+**.
- 자료를 고쳐 다시 뽑으면 같은 방법으로 다시 내려받는다(학습 기록이 덱에 묶이므로, 앱의 덱 갱신 메뉴가 있으면 그것으로).

## 빈칸 = GS 형광펜 (사용자 결정 2026-11-08)

- **판례(살구) · 조문(연두) · 취지·학설(하늘) 형광펜 구절 하나 = 빈칸 하나.** GS 가 칠한 범위 그대로(조사·어미가 밖이면 밖에).
- 사안(보라) 형광펜은 빈칸으로 하지 않는다. 사안 포섭·결론 문장은 자료에 넣지 않고 암기장 목차 아래 한 줄로.
- 형광펜 구절은 `../도구/gs_초안.py N --보기` 의 `{판 …}` `{조 …}` `{취 …}` 로 잡는다(글자 단위 판정). 글자는 GS 쪽 그림으로 고친다.
- 〔실증규청〕 꺾쇠 = 기본서(준특허법)의 두음 — 힌트로만. 없으면 `빈칸채우기.py` 가 빈칸 머리글자로 힌트를 만든다.
- 사건번호는 기본서에서 가져와 법령 DB 로 확인한 것만. 하급심은 「특허법원 判例」.

## 고친 뒤

```bash
cd 안쓰/특허법/도구
python 빈칸채우기.py --검사   # 빈칸 없는 판례 문장 · 60자 넘는 빈칸 · 빈칸 ↔ 정답 개수
python 빈칸채우기.py          # 빈칸채우기 · 빈칸정답 · 플래시카드 다시 뽑기
```

## 재료 (`../OCR/`, `../도구/`)

- `../OCR/박형준GS/NN회.md` — GS 회차별 **OCR 원문**(교정 전, 오타 있음). 굵은 말 = 판례·조문·취지 형광펜, `####` = 노란 목차 머리.
  GS PDF 는 글자가 그림이라 Windows 한국어 OCR 로 읽었다(`gs_ocr.py` → `gs_초안.py`).
- `../OCR/준특허법/NN장_*.md` — 기본서 장별 **OCR 원문**(ABBYY 글자층). 절 `## 2.3.1 …`, 쪽 `<!-- p.22 · pdf 33 -->`, 두음 낱말 **굵게**(`기본서.py`).
- 원본 PDF 는 `../원본/`(커밋 안 함).

이어 하는 순서와 남은 회차는 **`작업현황.md`**.

- 기본서 절·쪽은 `../도구/대응.py N`(GS 쪽 ↔ 기본서 쪽 8-gram 대응)으로 잡고 차례로 절 이름을 붙였다. 4회차부터는 사건번호를 달지 않았다(확인 필요한 것만 나중에).
