# 박형준 기초 GS 노트

박형준 「바주카포 동차용 정리 자료」 기초 GS+ 3～18회(보충문제 포함)를 **빈칸채우기**까지 만드는 노트.
가릴 말은 기본서 박형준 「준 특허법」의 **두음(굵은 첫 글자)** 에서 가져온다.

| 파일 | 무엇 | 만드는 법 |
|---|---|---|
| `암기장.md` | 문제마다 지문·물음 → 설문마다 **키워드 상자** · 기본서 자리 · **답안 목차(template)** · 사안 한 줄 | 손으로 (GS 쪽 그림 보고) |
| `자료.md` | 설문마다 답안에 쓸 **판례 · 조문 · 취지** 문장. 판례 문장에 사건번호 · 기본서 쪽 · 〔두음〕. **굵은 말 = 빈칸 키** | 손으로 |
| `빈칸채우기.md` | 자료의 굵은 말을 ❶(＿＿)로 가린 연습판, 설문 끝에 정답 | `../도구/빈칸채우기.py` 가 뽑는다 — **손으로 고치지 않는다** |

```
암기장(뼈대: 목차·키워드)  ──같은 문제·설문──▶  자료(외울 문장, 굵은 말)  ──빈칸채우기.py──▶  빈칸채우기
                                                    ▲
                                 기본서 두음(굵은 첫 글자) · 사건번호
```

## 빈칸 키 고르는 법

- 판례 문장이 기본서와 맞으면 **기본서의 두음 낱말**을 굵게 한다(「**실**질적 · **증**명책임 · **규**범적 · **청**구항별」 → 〔실증규청〕).
- 기본서에 두음이 없는 판례 구절은 핵심어 1～3개를 골라 굵게 하고 `<!-- 핵심어 -->` 를 단다.
- 조문·취지 문장은 굵게 하지 않는다(사용자 결정 2026-11-08 — 빈칸이 너무 많아지지 않게).
- 사건번호는 기본서에서 가져와 법령 DB 로 확인한 것만 적는다. 하급심은 「특허법원 判例」.

## 고친 뒤

```bash
cd 안쓰/특허법/도구
python 빈칸채우기.py --검사   # 빈칸 없는 판례 문장 · 15자 넘는 빈칸 · 〔두음〕 ↔ 빈칸 머리글자
python 빈칸채우기.py          # 다시 뽑기
```

## 재료 (`../OCR/`, `../도구/`)

- `../OCR/박형준GS/NN회.md` — GS 회차별 **OCR 원문**(교정 전, 오타 있음). **굵은 말** = 살구색(판례) 형광펜, `####` = 노란 목차 머리.
  GS PDF 는 글자가 그림이라 Windows 한국어 OCR 로 읽었다(`gs_ocr.py` → `gs_초안.py`).
- `../OCR/준특허법/NN장_*.md` — 기본서 장별 **OCR 원문**(ABBYY 글자층, 오타 있음). 절 `## 2.3.1 …`, 쪽 `<!-- p.22 · pdf 33 -->`, 두음 낱말 **굵게**(`기본서.py`).
- 노트를 쓸 때는 GS 쪽 그림을 보고 고치고, 두음은 기본서 쪽 그림으로 확인한다. 원본 PDF 는 `../원본/`(커밋 안 함).
